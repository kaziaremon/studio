# Whiz Studio Core Rules

- **100% FREE-PLAN-ONLY PROJECT**: Never activate paid plans, trials, subscriptions, paid API features, billing changes, or payment-method requirements.
- **Strict Task Scope**: Work only on the specific feature requested:
  - Design task → Focus on design.
  - Frontend task → Focus on frontend.
  - Backend task → Focus on backend.
  - Security task → Focus on security.
- **Minimal Essential Expansion**: Expand scope only for dependencies strictly essential to the requested fix.
- **Preserve Working Architecture**: Preserve existing working functionality, routes, and project architecture without unnecessary rewrites.
- **Quality Standards**: Maintain premium visual design, mobile responsiveness, accessibility, and high code quality.
- **Data Protection**: Never expose credentials, API keys, or compromise client data.
- **Production Safety**: Avoid unnecessary code rewrites, unsolicited refactoring, and unrequested production modifications.
